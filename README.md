# File Organizer GUI with Tkinter
 - This Python application provides a graphical user interface (GUI) to organize files by their extensions into specified directories.

## Features
- Select a directory to organize.
- Group files by their extensions into corresponding subdirectories.
- Generate sample empty files for testing purposes.
- Easy-to-use GUI with Tkinter.

## Requirements
- Python 3.x
- Tkinter (usually comes with Python installation)

## Usage
- Clone the repository or download the source code.
- Install any dependencies
- Run the application 
  - python main.py 
- The GUI window will appear. Follow the instructions on the screen to select a directory and organize files.

- Optionally, use the "Generate Test Files" button to create sample empty files in the selected directory for testing the application's functionality.

## How It Works
- Select Directory: Click the "Select Directory" button to choose the directory you want to organize.
- Organize Files: Once a directory is selected, click "Organize Files" to move files into subdirectories based on their extensions (e.g., .txt files will be moved to a txt directory).
- Generate Test Files: Click the "Generate Test Files" button to create sample empty files in the selected directory. This feature is useful for testing the application's file organization functionality.
